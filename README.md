# CrispList Website

The support page and privacy policy for **CrispList: Shopping List**, a fast, simple shopping list app for iPhone.

## Pages

| Page | URL |
| --- | --- |
| Support | https://crisplist.github.io/ |
| Privacy Policy | https://crisplist.github.io/privacy.html |

## Files

| File | Description |
| --- | --- |
| `index.html` | Support page with FAQ and contact info |
| `privacy.html` | Privacy policy |
| `icon.png` | App icon used in the header, on the support page, and as the browser icon |

## Hosting

The site is hosted for free with GitHub Pages and deploys automatically from the `main` branch. Changes usually go live within a few minutes of each commit.

Both pages are self-contained HTML with no external scripts, fonts, cookies, or analytics. They support light and dark mode automatically.

## Updating the privacy policy

When the app changes how it handles data (for example, adding sync or list sharing):

1. Update `privacy.html` to describe the new behavior.
2. Change the **Effective date** at the top of the policy.
3. Update the **App Privacy** answers in App Store Connect to match.
